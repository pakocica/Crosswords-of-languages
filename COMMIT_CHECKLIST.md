# Commit Checklist

Before submitting:

1.  **Update Version Number**: Increment the version number in the `<title>` tag of `index.html` (e.g., from `v1.1` to `v1.2`). Use a two-number scheme (e.g., `X.Y`).
2.  **Descriptive Commit Message**: Ensure the commit message clearly describes the changes made.
3.  **Branch Name**: Use a short, descriptive branch name.
